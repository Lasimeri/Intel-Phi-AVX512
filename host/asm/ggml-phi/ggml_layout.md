# ggml_layout.inc

The ggml structures' offsets, sizes and enum values the glue needs, as
`.set` symbols: generated by `tools/ggml-layout-check.c --gen` from
llama.cpp's own headers (`ggml.h`, `ggml-impl.h`, `ggml-backend.h`,
`ggml-backend-impl.h`, `ggml-cpu.h`), and compared with them again by
`make layout-check`, which fails on any difference. Nothing here is
written by hand; a llama.cpp whose layout differs regenerates the file
and the glue follows.

| group | symbols |
| --- | --- |
| `struct ggml_tensor` | `T_BYTES`, `T_TYPE`, `T_BUFFER`, `T_NE`, `T_NB`, `T_OP`, `T_OP_PARAMS`, `T_FLAGS`, `T_SRC`, `T_VIEW_SRC`, `T_DATA`, `T_NAME`, `GGML_MAX_SRC` |
| `struct ggml_cgraph` | `CG_N_NODES`, `CG_NODES` |
| buffers | `BUF_BUFT` |
| `struct ggml_backend_reg` and its interface | `REG_BYTES`, `REG_API_VERSION`, `REG_IFACE`, `REG_CONTEXT`; `REG_I_BYTES` and the slots `REG_I_GET_NAME`, `REG_I_GET_DEVICE_COUNT`, `REG_I_GET_DEVICE`, `REG_I_GET_PROC_ADDRESS` |
| `struct ggml_backend_device` and its interface | `DEV_BYTES`, `DEV_IFACE`, `DEV_REG`, `DEV_CONTEXT`; `DEV_I_BYTES` and every slot from `get_name` to the three event functions |
| `struct ggml_backend` and its interface | `BE_BYTES`, `BE_GUID`, `BE_IFACE`, `BE_DEVICE`, `BE_CONTEXT`; `BE_I_BYTES`, `BE_I_GET_NAME`, `BE_I_FREE`, `BE_I_GRAPH_COMPUTE` and the rest |
| `struct ggml_backend_dev_props` | `PROPS_NAME`, `PROPS_DESCRIPTION`, `PROPS_MEMORY_FREE`, `PROPS_MEMORY_TOTAL`, `PROPS_TYPE`, the four `caps` bytes |
| by-value structs | `INIT_BYTES` (`ggml_init_params`, 24 bytes, passed in memory), `TPP_BYTES` (`ggml_threadpool_params`, 528 bytes, returned through a hidden pointer) with `TPP_N_THREADS`, `TPP_POLL` |
| enums | `GGML_BACKEND_API_VERSION`, `GGML_TYPE_*`, `GGML_OP_*`, `GGML_GLU_OP_SWIGLU`, `GGML_TENSOR_FLAG_*`, `GGML_STATUS_*`, `GGML_BACKEND_DEVICE_TYPE_*`, `GGML_HINT_SRC0_IS_HADAMARD` |

The interface tables are built at run time by the glue (`tables_init`)
from these offsets, one pointer per named slot, the rest null: the
layout of ggml's tables is not assumed by position anywhere.

Run the checker by hand with

```
L=$HOME/llama.cpp
tcc -I$L/ggml/include -I$L/ggml/src -run tools/ggml-layout-check.c host/asm/ggml-phi/ggml_layout.inc
```

and regenerate with `--gen` in place of the file name.
